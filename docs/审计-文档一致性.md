## 总处置原则

- 文档超前 → 删除或改标「未实装 / 预留 / 规划中 / 占位」（与既有「预留」标注口径一致）；
- 码超前 → 补文档（migrate 全家、registry export/import/push、远程源四 crate、template target、JSON/CSV options 等）；
- 描述不符 → 按源码实际行为改写（wire 格式、默认值、退出码、求值器占位态、错误码触发条件）。
- P0（会误导使用的实质错误）11 条全部清零；P1（缺项/口径偏差）25 条全部清零；P2（措辞/补全）37 条全部清零。
