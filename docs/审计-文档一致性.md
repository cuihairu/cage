### 三、语言面（G2 新增探针）

- **结论**：VitePress 双语站（`locales: ['root','zh']`），**无浏览器语言自动识别**——配置里没有
  `rootLocale`、没有 JS 语言探测，访问者落到哪个 locale 只由自己点的链接决定。
- **本地复核**：`docs/.vitepress/config.mts` 无 rootLocale 重定向、无 `navigator.language` 探测；
  构建产物 `docs/.vitepress/dist/index.html` 为 `lang="en-US"`、`dist/zh/index.html` 为 `lang="zh-CN"`，
  两条语言线各自成立。
- **站点契约正常**：根 `/` → 200 / en-US，`/zh/` → 200 / zh-CN，中英两版互相有链接可达。
- **附带发现（G2-09）**：中文首页留了一段记录「英文首页重定向」的 `<script setup>`，而该重定向
  行为在配置里已不存在，localStorage 键也无任何消费方——属失效残留，已删除（文档侧清理，非部署改动）。
- **处置**：按规范只登记为 P2 发现，**不改部署**；是否引入 `rootLocale` 浏览器语言重定向由产品拍板。
